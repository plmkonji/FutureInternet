# The Internet From 2057

A fictional future internet you can explore in the browser. Visit news, social media, shopping, and a public memory archive while uncovering inconsistencies hidden across the network.

## Run it

Open `index.html` directly, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy on GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

No build step or dependencies are required.
